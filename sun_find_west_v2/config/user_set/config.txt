
===Camera===

---basic_parameters---
exposure   : 100    /ASI_EXPOSURE: 露出時間 (μs)。ASI432MMスペック範囲: 32μs〜2000s。ND5.0太陽観測用推奨: 100〜1000
gain       : 0      /ASI_GAIN: ゲイン (0〜400)。太陽観測は基本0。HCGモードはGain 140で自動ON(低ノイズ化)
offset     : 15     /ASI_OFFSET or ASI_BRIGHTNESS: オフセット (黒レベルの切り捨て防止)
gamma      : 50     /ASI_GAMMA: ガンマ補正値 (50=補正なし リニア特性維持)

---transfer_settings---
band_width : 80     /ASI_BANDWIDTHOVERLOAD: USB3.0転送帯域幅の制限 (%)
high_speed_mode : True   /ASI_HIGH_SPEED_MODE: ハイスピードモード (グローバルシャッター120fps動作用)
hardware_bin : 1      /ASI_HARDWARE_BIN: ハードウェアビンニング (9.0μmの大ピクセルのため基本1)
flip       : 0      /ASI_FLIP: 画像反転 (0:なし, 1:水平, 2:垂直, 3:両方)

---auto_control---
auto_max_gain : 0      /ASI_AUTO_MAX_GAIN: 自動ゲイン上限 (解析時の閾値維持のため固定値運用時は0)
auto_max_exp : 1      /ASI_AUTO_MAX_EXP: 自動露出上限 (ms)
auto_target_brightness : 100    /ASI_AUTO_TARGET_BRIGHTNESS: 自動露出の目標明るさ

---image_format---
img_type   : RAW8   /img_type: 画像フォーマット (ASI432MMはモノクロ専用。高速解析はRAW8、高階調は12bit RAW16)
