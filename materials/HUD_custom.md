# 太陽軌道解析 HUD（ヘッドアップディスプレイ）調整マニュアル

画面上に表示される解析数値（角度、MIN2情報、フレーム数、FPSなど）のレイアウトやスタイルは、`lib/drawer.py` 内の `Visualizer` クラスにある **`self.hud_style` 辞書**の数値を書き換えるだけで、一元的に調整可能です。

## 設定箇所
`lib/drawer.py` の `__init__` メソッド内にある以下の辞書を編集します。

```python
self.hud_style = {
    "x": 0.02,  # 画面左端からの位置 (0.0 ~ 1.0)
    "y": 0.98,  # 画面下端からの位置 (0.0 ~ 1.0)
    "ha": "left",  # 水平方向の揃え (left, center, right)
    "va": "top",  # 垂直方向の揃え (top, center, bottom)
    "fontsize": 13,  # 文字サイズ
    "color": "#00FF00",  # 文字色
    "family": "monospace",  # フォント
    "bbox": dict(...),  # 背景パネルの設定
}
```

## 各パラメータの調整方法

### 1. 位置の調整 (`x`, `y`)

matplotlibの「Figure座標系」を使用しているため、画像サイズに依存せず一定の比率で配置されます。

* `x`: `0.0` (左端) ～ `1.0` (右端)
* `y`: `0.0` (下端) ～ `1.0` (上端)
* **例:** 右下に配置したい場合は `x: 0.98`, `y: 0.02`, `ha: "right"`, `va: "bottom"` に設定します。

### 2. テキストの揃え (`ha`, `va`)

座標 (`x`, `y`) を基準にテキストをどう整列させるかを決めます。

* **`ha` (Horizontal Alignment):** `left` (左揃え), `center` (中央揃え), `right` (右揃え)
* **`va` (Vertical Alignment):** `top` (上揃え), `center` (中央揃え), `bottom` (下揃え)

### 3. 大きさとスタイルの調整 (`fontsize`, `color`, `family`)

* **`fontsize`:** 数値を変更するだけで全体の文字サイズが拡大・縮小されます。
* **`color`:** カラー名（`"yellow"`, `"cyan"` など）またはカラーコード（`"#FF5733"` など）を使用できます。
* **`family`:** `monospace` (等幅) に設定することで、数値が変動してもテキスト幅がガタつかず視認性が向上します。

### 4. 背景パネルの調整 (`bbox`)

背景の半透明な黒いボックスの見た目を調整します。

* `facecolor`: 背景色（デフォルトは `'black'`）
* `alpha`: 透明度（`0.0` 完全に透明 ～ `1.0` 不透明）
* 不要な場合は、`self.hud_style` 辞書から `"bbox"` の項目ごと削除するか、`None` を指定してください。
